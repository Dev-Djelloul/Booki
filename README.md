# Booki

Booki est un site vitrine pour une agence de voyage. Le projet met en pratique les bases HTML/CSS, la mise en page responsive et l'integration d'une interface de recherche.

## Apercu

- Page d'accueil avec sections hebergements, activites et informations.
- Barres de recherche et filtres d'affichage.
- Cartes d'hebergements et d'activites.
- Design responsive.

## Contenu

- Hero et navigation vers les sections principales.
- Filtres (economique, familial, romantique, pepites).
- Grilles de cartes pour hebergements et activites.

## Stack technique

- HTML5
- CSS3

## Lancer le projet

Ouvrir `index.html` dans un navigateur.
